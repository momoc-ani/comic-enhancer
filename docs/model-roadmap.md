# 模型路线与验收

## 首版模型组合

| 环节 | 首版选择 | 原因 |
| --- | --- | --- |
| 基础生成 | SD1.5 动漫 checkpoint | 8GB 到 12GB 显卡可运行，4090 可做秒级低步数推理 |
| 结构保持 | ControlNet Lineart SD1.5 | 直接利用漫画线稿，减少人物和构图漂移 |
| 画质增强 | Real-ESRGAN Anime 6B | 对动漫线条和低清页面成本较低 |
| 独立放大档 | Real-CUGAN SE 2x | 不经过上色模型，跨平台原生执行并固定无降噪 |

2026-08-14 对质量工作流做了三组 3 页冒烟 A/B。当前候选使用 20 步、CFG 6.8、denoise 0.70 和 Lineart ControlNet strength 1.02；远端完整 API 热推理 3/3 成功，P50 5.416 秒、P95 5.549 秒，墨线、中文和白底结构保留正常，有效色相中位数为 5，最差页主导色占比为 51.95%。但最终饱和色覆盖中位数只有 3.06%，人工检查仍以灰白和浅色点缀为主，不能判定当前 SD1.5 全页方案达到目标画质。本轮只作为保守增量改进，最终结论仍需新的模型路线和至少 100 页授权集。

## 后续候选基准

使用至少 100 页、经过授权的测试集比较：

当前已增加 `scripts/benchmark_api.py` 和 `benchmarks/` 清单格式，可记录完整 API 的实际模型档位、角色参考生效情况、耗时、尺寸、明度与深色墨线保留。现有 3 页仅作为本地非商用冒烟集；详细准入门禁见 `benchmarks/README.md`。

- DDColor-Tiny：ONNX 速度基线，不作为漫画最佳效果的默认结论。
- manga-colorization-v2：漫画专项研究基线，发布前必须重新核对代码和权重许可证。
- SD1.5 Anime + Lineart ControlNet + IP-Adapter：8GB 主力候选。
- Cobra 多参考上色：第一候选，代码和权重均为 Apache-2.0；分别测试 2、4、8、12 张参考图，并记录 PixArt/T5 常驻显存、首轮加载时间与热推理耗时。
- FLUX.2 Klein 4B FP8：第二候选，Apache-2.0 蒸馏 4 步路线；使用同一批漫画页和角色参考图对比人物颜色一致性、文字/墨线保持、颜色丰富度、耗时和显存。只有同集实测优于 Cobra 时才切换默认高质量候选。
- Anima Base v1.0 + Anima LLLite Lineart：非商业实验档，约 1MP 空 latent 上色，验证动漫平涂、线稿条件和角色服装颜色稳定性；不调用页面 VLM、不使用角色参考图、不走 Real-CUGAN 二阶段。
- Anima-2.9B Preview v1：非商业实验档，0.85MP 低降噪图生图，验证 12GB 级显存的二次元上色可行性；与 Anima Base 独立比较，不改变默认路由。
- Real-ESRGAN Anime 6B：测试 1x 修复、2x 输出和文字线条清晰度。
- Real-CUGAN SE：独立放大档固定测试 2x、无降噪输出，记录文字、气泡、网点、细线、耗时、Vulkan 设备和连续页面稳定性；Windows、Linux 和 macOS 平台结果必须分别记录。

2026-08-16 在 RTX 4090 上完成两条 Anima 完整 API 链路冒烟。`anima_base` 约 14.1 秒返回 `1124x1600` 工作流直出结果，但明显重绘人物、场景和文字；`anima_2_9b` 挂载官方 loader patch 后约 15.5 秒返回非空结果，正式参数保持 `denoise=0.35`，输出仍基本为灰度且会改写文字。额外测试的 `denoise=0.45/0.55/0.65` 虽逐步增加颜色，但人物身份、页面内容和文字漂移同步加重。现有 Base LLLite 只覆盖 28 层，不能用于 40 层的 2.9B 模型。两档均只保留为可运行的非商业实验档，不通过“只上色、不重绘”质量门禁，也不进入默认路由。

同日追加 RTX 4090 参数扫描：2.9B 在 `denoise=0.35~0.45、CFG=3~4` 时饱和色覆盖最高约 `0.75%`，暗线保留约 `66%~72%`；降低到 `denoise=0.25~0.35、CFG=1.5~2` 后暗线最高约 `78.5%`，但饱和色覆盖为 `0%`。Base 的 LLLite 强度 `0.8~1.4` 虽产生约 `31%~60%` 饱和色覆盖，暗线保留均低于 `1%`。参数扫描未发现可同时满足颜色覆盖与线稿/文字保持的窗口，正式参数不调整。

“开源可见”不等于“允许重新分发权重”。每个候选都必须单独登记代码许可证、权重许可证和训练数据声明。

## 性能目标

| 场景 | 目标 |
| --- | --- |
| 缓存命中 | 不超过 300ms |
| RTX 4090 快速模式热模型 P50 | 不超过 2.5s |
| RTX 4090 快速模式热模型 P95 | 不超过 4s |
| RTX 4060 / 8GB | 降低分辨率，目标数秒级，不承诺与 4090 同档 |
| 连续阅读 | 当前页优先，至少预处理后续 3 页 |

## 画质验收

- 原有文字和对话框可读。
- 线稿轮廓、人物身份和构图不发生明显变化。
- 相邻页面主要角色颜色保持一致。
- 失败时显示原图，不出现空白页。
- 连续处理 100 页，显存和进程内存不持续无界增长。
- 分别记录冷启动、热模型、缓存命中数据，不能混在同一性能结论中。
